# Медиаматериалы

[← О проекте](../README.md)

Использованы существующие материалы для страницы Tiny Swords: Kingdoms в VK Play. Новая съёмка или генерация изображений для портфолио не выполнялась.

| Файл | Происхождение |
| --- | --- |
| `01-kingdom.jpg` | Кадр 03 из сохранённого набора русской галереи VK Play |
| `02-landscape.jpg` | Кадр 05 из той же галереи |
| `03-army.jpg` | Кадр 10 из той же галереи |
| `04-battle.jpg` | Кадр 12 из той же галереи |
| `05-siege.jpg` | Кадр 14 из той же галереи |
| `trailer-poster.png` | Готовая обложка русского трейлера от 6 сентября 2026 года |
| `tinyswords-trailer-720p.mp4` | Русский трейлер от 6 сентября 2026 года, 81 секунда; версия 720p для репозитория |
| `gameplay-preview.webm` | Превью версии 1.0.20, сохранённое в оформлении VK Play: 336×188, 9 секунд, без звука |

Скриншоты, постер и WEBM скопированы без изменений. MP4 перекодирован из готового мастера 1080p в 720p, без сокращения и перестановки сцен. Основная часть трейлера содержит запись геймплея; пролог и финальный бой на карточке являются рекламным оформлением. Короткое WEBM-превью показывает постановочный бой с настоящей игровой симуляцией.

Материалы показывают состояние игры на момент записи и не служат подтверждением номера её текущей версии.

## Авторы использованных материалов

- Игровая графика: [Pixel Frog — Tiny Swords](https://pixelfrog-assets.itch.io/tiny-swords).
- Музыка трейлера: Spring Spring — [War Theme ver. 2](https://opengameart.org/content/war-theme), CC0.
- Звуки мечей в трейлере: StarNinjas — [20 Sword Sound Effects](https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes), CC0 согласно документации готового трейлера.
- Шрифт оформления трейлера: [Russo One](https://github.com/google/fonts/tree/main/ofl/russoone), Jovanny Lemonad, SIL OFL 1.1.

Исходные наборы спрайтов, аудиофайлы и файлы шрифта в репозиторий не включены.
